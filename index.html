  • Local-first за задумом: усі фінансові записи лежать у базі на пристрої й нікуди не передаються. Немає сервера — немає й витоку. Local-first by design: every financial record stays in an on-device database and never leaves it. No server means nothing to leak.

  • Монетизація: Google Play Billing для Pro-версії та банер AdMob у безкоштовній, із запитом згоди для користувачів ЄЕЗ. Monetisation: Google Play Billing for the Pro tier and an AdMob banner in the free one, with a consent prompt for EEA users.

Osnova TV

Android · релізи публічніAndroid · public releases

Android-застосунок із власним каналом оновлень замість магазину застосунків. Android app with its own update channel instead of an app store.

поточний релізcurrent release: опублікованоpublished:
  • Механізм оновлення власноруч: маніфест version.json із кодом і назвою версії, посиланням на APK, контрольною сумою SHA-256 та прапорцем обов'язкового оновлення. Hand-rolled update mechanism: a version.json manifest carrying version code and name, APK link, SHA-256 checksum and a mandatory-update flag.
  • Перевірка цілісності: збірка звіряється з контрольною сумою до встановлення — підміна APK на шляху не пройде. Integrity check: the build is verified against its checksum before installation, so a swapped APK does not get through.
  • Push-сповіщення через Firebase Cloud Messaging; вихід із застосунку відв'язує пристрій від розсилки. Push notifications via Firebase Cloud Messaging; signing out unsubscribes the device.
  • Регулярні релізи: чотири версії від 2.0 до 2.3 із нотатками до кожної — канал збірок відкритий. Steady releases: four versions from 2.0 to 2.3, each with release notes — the build channel is public.
