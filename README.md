# Alesko125.github.io

Особиста сторінка-резюме Олексія Кобзаря — двомовна (UA / EN), без фреймворків
і без збірки. Один файл [`index.html`](index.html): розмітка, стилі та скрипт
усередині.

**Онлайн:** https://alesko125.github.io

## Що вміє сторінка

- **UA / EN** — перемикач у шапці, вибір зберігається в `localStorage`.
  Початкова мова визначається за мовою браузера.
- **Темна / світла тема** — теж із запам'ятовуванням; за замовчуванням береться
  системна.
- **Друк у PDF** — кнопка `PDF` або `Ctrl+P`. Друкована версія світла, без
  навігації, з розгорнутими посиланнями.
- **Жива статистика релізів** — картка Osnova TV показує поточну версію, дату
  публікації та кількість релізів, узяті з GitHub API при завантаженні. Дані
  переформатовуються під мову при перемиканні. Якщо API недоступний або
  вичерпано ліміт запитів — блок просто ховається, решта сторінки працює.

## Публікація

Репозиторій названо `Alesko125.github.io`, тому GitHub Pages віддає його з
кореня домену:

1. Створити на GitHub порожній публічний репозиторій **`Alesko125.github.io`**.
2. `git push -u origin main`
3. Settings → Pages → Source: **Deploy from a branch**, гілка `main`, тека `/ (root)`.

Файл `.nojekyll` вимикає обробку Jekyll — статика віддається як є.

## Як правити текст

Кожен перекладений фрагмент — пара сусідніх елементів:

```html
<span class="ua">Текст українською</span><span class="en">Text in English</span>
```

CSS ховає той, що не відповідає поточній мові. Додаючи новий текст, додавайте
обидві мови — інакше в одній із версій буде порожньо.
